## 🧩 Descrição do Projeto

**TRIX** é um jogo inspirado no clássico **Tetris**, desenvolvido em **Python** utilizando a biblioteca **Pygame**.  
O jogador deve posicionar blocos que caem para formar linhas completas, sem deixar espaços vazios.  
O projeto inclui:
- Uma **tela inicial interativa** com botão de início;  
- Uma **tela de informações** explicando as regras;  
- O **jogo principal** com pontuação em tempo real;  
- E uma **tela de fim de jogo**.

---

## 🕹️ Como Jogar

- **←** Move o bloco para a esquerda  
- **→** Move o bloco para a direita  
- **↓** Faz o bloco cair mais rápido  
- **↑** Gira o bloco  
- **ENTER** ou **clique em "INICIAR"** para começar o jogo  

O objetivo é completar linhas horizontais.  
Cada linha completa aumenta sua pontuação.  
Quando o tabuleiro fica cheio, o jogo acaba.
